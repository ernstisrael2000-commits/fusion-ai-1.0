# Fusion AI 1.0

## Run on Replit

The project is a static, browser-based application. The `Start application` workflow serves the workspace root on port 5000 with Python's built-in HTTP server; `index.html` opens the Fusion AI studio.

The original creation flow, project storage, image tools, and JSON/text/ZIP exports remain in `Fusion-AI-1.0-Creator-Fix.html`. Projects are saved locally in the current browser. AI image generation requires an Agnès API key configured in the app. Groq keys are optional for text generation.

No install step is needed. Start the configured workflow to open the app in the Replit preview.
